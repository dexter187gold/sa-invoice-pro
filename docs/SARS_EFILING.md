# SARS eFiling / e@syFile – what is possible

## Reality
SARS does **not** publish a general public API for arbitrary desktop apps to submit EMP201/IRP5 as a full eFiling replacement without becoming an approved vendor / using official channels.

## Official links
- SARS eFiling: https://www.sarsefiling.co.za/
- e@syFile Employer: https://www.sars.gov.za/types-of-tax/paye/easing-the-burden-on-employers/
- SARS software & guides: https://www.sars.gov.za/

## What SA Invoice Pro provides (v2.2)
- **Payroll export pack** (CSV) for employee / payslip data you can use when completing EMP201 / reconciliations manually or in e@syFile.
- Links from the Payroll page to SARS portals.
- This is **not** live submission to SARS.

## Path to full integration later
1. Register as software provider / use SARS-approved interfaces when available.
2. Maintain official tax tables yearly.
3. Legal review of employer obligations.
