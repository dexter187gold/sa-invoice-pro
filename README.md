Product: **sainvoicepro@gmail.com**

## Licensing and trial access

New accounts receive a limited basic-workspace trial. Paid Solo, Shop and Multi-branch plans unlock their entitled modules after the licence server confirms payment and activates the account. Payment confirmation is server-verified; browser return pages are not proof of payment.

The owner billing ledger is available from the licence server at `/admin/billing`. Production builds deploy from the `main` branch. The canonical app is https://sa-invoice-pro.pages.dev; the original Worker endpoint remains active at https://sa-invoice-pro.pcrepairdex.workers.dev for API compatibility and rollback.
