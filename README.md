# SA Invoice Pro 6.23.0

**Sell-ready offline-first invoicing for South African IT / mobile repair / MSP benches.**

Tax invoices · job cards · quotes · **portal Accept/Decline with server write-back** · inter-branch stock · seats · white-label · bank match.

## Quick start

```bash
npm install
npm run dev
npm run build
npm run test:unit
npm run test:e2e
```

Optional API + portal store:

```bash
cd server && npm install && npm start
```
