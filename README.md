## What works (IT desk)

- Invoices, quotes, clients, VAT, PDF with company logo
- Job desk (kanban, Snipe → invoice, multi-job bill, soft-delete / recycle bin)
- Streaming backup import + OPFS recovery snapshots
- License activation, device limits, owner gating
- Client portal link + PIN path
- Document studio (IT templates) + vertical catalog packs
- WhatsApp desk / inbound reply packs (expanding)

## Honest release status

- **Product (web IT path):** usable for pilot shops with backups.
- **CI on tip:** must be green before calling a build “release” (version files, e2e, APK, Windows).
- **Windows:** SmartScreen until Authenticode. **Play Store:** not listed yet.

## Quick start

1. Open the live app and complete company setup.
2. Settings → choose **IT / MSP** business type → install IT catalog pack if offered.
3. Create a client → quote or job card → invoice.
4. Settings → Backup → download a JSON backup before large imports.
